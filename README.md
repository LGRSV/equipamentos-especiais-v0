# Equipamentos Especiais · mapa, fluxo, material e histórico

Aplicação web estática para acompanhar religadores e reguladores indisponíveis, visualizá-los no mapa e concentrar a etapa atual do fluxo, a decisão de material e o histórico de SS por ativo.

A versão inicial usa o corte real de 29/06/2026 das bases analisadas no projeto.

> Esta primeira alteração inicializa a branch para receber a aplicação completa e os dados operacionais consolidados.
